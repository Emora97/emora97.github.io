## Overview
This project acts as an extension to a project on drone trajectory automaton, flight data logging and validation. The current implementation is limited to single camera use but has served as a foundation for deeper research regarding a proposed six camera motion capture system for dedicated drone and robotics tracking. Details regarding this proposed system are available upon request.
